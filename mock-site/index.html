귀가 픽업 서비스

버튼 한 번으로
안전한 귀가 확인

부모님 외출 일정이 종료될 때 자녀에게 알림이 가고, 버튼 한 번으로 카카오택시를 자동 호출합니다. 귀가 완료까지 실시간 위치를 공유하고, 귀가 후 자동으로 공유가 종료됩니다.

  • 1부모님 외출 종료 30분 전 자녀에게 알림
  • 2[택시 지금 호출] 버튼 → 저장된 주소로 자동 호출
  • 3부모님 앱 "OO이가 택시를 보냈어요" 알림
  • 4귀가 완료 감지 → "안전하게 귀가하셨어요" 알림
  • 5위치 공유 자동 종료 (사생활 보호)
